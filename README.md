# Quire

A study desk for retrieval practice, spacing, and the other methods with real evidence. Cards stay in the browser on the device where you study.

## Run it

```bash
npm install
npm run dev
```

Then open the address printed in the terminal. `npm run build` produces the production bundle.

## What it is not

Quire is a web app. It is not a Google Play package. Play requires a signed Android App Bundle and a Play Console account in your name. A store wrapper also needs either a public web address to open, or a separate static build packaged inside the app. This repository is the source.
